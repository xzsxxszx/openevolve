# OpenEvolve 网页应用

这是一个为 `openevolve` 库提供图形化用户界面的Web应用。

## 功能
- 通过网页界面配置和启动代码演化任务。
- 实时追踪演化进度，包括当前代数和最佳分数。
- 支持高级选项，如指定LLM模型和种群大小。
- 支持通过 `#start evolve` 和 `#end evolve` 注释来指定需要优化的代码区域。

## 启动说明

### 1. 环境设置

首先，请确保您已安装 Python 3.10+。

克隆或下载本仓库代码后，在项目根目录下打开终端，然后运行以下命令安装所需的依赖包：

```bash
pip install -r requirements.txt
```

### 2. 启动Web服务

安装完依赖后，运行以下命令来启动Web应用服务：

```bash
python app.py
```

您应该会看到类似以下的输出，表示服务已成功启动：
```
 * Running on http://0.0.0.0:8080
 * Running on http://127.0.0.1:8080
```

### 3. 使用Web界面

服务启动后，打开您的网页浏览器，访问以下地址：

[http://localhost:8080](http://localhost:8080)

在网页上，请按照以下步骤操作：
1.  **提供API密钥**: 输入您的OpenAI兼容的API密钥。
2.  **输入初始程序**: 粘贴您希望优化的完整Python代码。
3.  **输入评估函数**: 提供一个Python函数，用于评估优化后代码的性能。
4.  **配置参数**: 设置最大迭代次数等基本参数，或在“高级选项”中进行更详细的配置。
5.  **开始演化**: 点击“开始演化”按钮来启动任务。
6.  **查看进度**: 程序会自动切换到“实时追踪”标签页，您可以在此查看任务的实时状态。
